# Amanda Chan

I make LLM agents trustworthy to delegate to: I validate the measurement before trusting the number, and I design harnesses where the agent doing the work never certifies it.

- [Agent Rule of Law](https://github.com/amandachan-ai/agent-rule-of-law): governing delegation in coding agents
- [Self-Sealing Revisions](https://github.com/amandachan-ai/self-sealing-revisions): do an agent's self-written lessons foreclose its own future evidence? (negative result)
- [Your Eval Is Lying](https://github.com/amandachan-ai/your-eval-is-lying): failure modes of LLM measurement itself
- [Agent Harness Playbook](https://github.com/amandachan-ai/agent-harness-playbook): layering rules, knowledge, workflows and capabilities in agent harnesses
